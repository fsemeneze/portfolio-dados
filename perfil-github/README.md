## 🇧🇷 Sobre mim

Atuo como Analista de Dados na indústria de saúde domiciliar, construindo soluções de ponta a ponta: pipelines de ETL orquestrados com IA generativa (LangGraph), APIs em FastAPI, RPA com validação de dados, e dashboards estratégicos em Power BI.
